Veyra Optical Store & Eye Care Center

A premier modern minimalist HTML5 template combining practical eyewear e-commerce (inspired by Lenskart) with high-end editorial storytelling and healthcare precision (inspired by Warby Parker).

3. Page Architecture

This template intentionally does not require an admin or customer dashboard. All authentication flows (login, registration) are standalone UI demonstrations that lead gracefully to guest shopping.

4. Strict Three-Color System

The visual system strictly adheres to exactly three brand colors defined in CSS variables:

:root {
  --color-black: #111827;       /* Black foundation & typography */
  --color-white: #FFFFFF;       /* White canvas & contrast surfaces */
  --color-primary: #C2410C;     /* Sedona Terracotta */
}

5. Strict Two-Font System

Only two Google Fonts are loaded throughout the entire template:

  • Heading Typography: 'Playfair Display', serif (High-end editorial prestige)
  • Body & UI Typography: 'Plus Jakarta Sans', sans-serif (Clean, modern clinical legibility)

6. Layout, 30px Spacing & Tablet/Mobile Menu Bars

The layout spans 100% full width and maintains exactly 30px horizontal padding on both left and right sides across ALL devices (Desktop, Tablet, and Mobile) via .site-container, .site-header-inner, .site-footer-inner, .mobile-menu-bar-inner, and .mobile-bottom-nav-inner:

.site-container,
.site-header-inner,
.site-footer-inner,
.mobile-menu-bar-inner,
.mobile-bottom-nav-inner {
  width: 100% !important;
  max-width: 100% !important;
  padding-left: 30px !important;
  padding-right: 30px !important;
  box-sizing: border-box !important;
}

Tablet & Mobile Dual Menu Bar System: On screen widths below 1024px, the template introduces two dedicated menu bars:

  • Header Quick-Links Menu Bar: A sleek, horizontally scrollable category and page menu bar positioned directly beneath the header with smooth momentum scrolling.
  • Bottom App Menu Bar: A fixed thumb-friendly bottom bar featuring Home, Catalog, Book Exam, Cart Drawer, and Menu.

7. Dark and Light Theme System

The template detects the user's system preference (prefers-color-scheme) upon initial load and stores any manual toggle in localStorage.getItem('stackly-theme'). When dark mode is active, data-theme="dark" is attached to the <html> element, and dark-mode.css seamlessly shifts surfaces to deep midnight tones while strictly preserving the primary brand color (#C2410C) and high accessibility contrast.

8. Right-to-Left (RTL) Layout Mirroring

Clicking the RTL toggle in the desktop header or mobile drawer sets dir="rtl" on <html> and toggles rtl.css. Layouts mirror horizontally:

  • Logo floats to the right, shopping actions to the left.
  • Filter sidebars shift to the right of product listings.
  • The slide-in shopping cart drawer slides from the left side instead of the right.
  • Toast notifications appear on the bottom-left corner.
  • Directional chevron and arrow icons automatically flip horizontally.

9. Product Catalog & Interactive Filtering

The catalog in products.html is dynamically driven by products.js. Buyers can customize or add new eyewear models by modifying the STACKLY_PRODUCTS array. Real-time client filtering includes:

  • Full-text search matching name, shape, or description.
  • Shape filter: Rectangle, Round, Square, Aviator, Cat-Eye, Wayfarer, Geometric, Rimless.
  • Lens Type filter: Single Vision, Progressive, Blue-Light, Polarized.
  • Price range slider ($50 to $300).
  • Sort by price, rating, or newest.
  • Grid vs. List view toggle.

10. Shopping Cart & Wishlist System

The shopping cart persists in localStorage under stackly-cart-v1. Features include:

  • Slide-in Cart Drawer accessible on every page.
  • Quantity adjustments (+ / -) and item deletion.
  • Interactive Free Shipping threshold progress bar ($150 goal).
  • Promo code support (e.g. VEYRA10 grants a 10% discount).
  • Heart wishlist toggle with reactive counters.

11. Eye Test 7-Step Stepper

Located at eye-test.html and orchestrated by booking.js:

  1. Step 1: Select Examination Type (Comprehensive, Contact Fitting, Retinal Scan, Pediatric).
  2. Step 2: Select Store Location (Downtown, Soho, Uptown).
  3. Step 3: Select Date from interactive 14-day calendar.
  4. Step 4: Select Available Time Slot.
  5. Step 5: Patient Legal Contact Details & Vision Insurance.
  6. Step 6: Review Summary Card.
  7. Step 7: Generated Booking Reference ID (e.g. #STK-84920) with print and calendar export actions.

12. Virtual Try-On AR Simulation

Accessed via any product card or details page. It provides:

  • Studio Mode: 3D high-resolution model preview with live PD (Pupillary Distance) measurement guide.
  • Live Webcam AR: Requests browser camera permissions (navigator.mediaDevices.getUserMedia) to project glasses onto the user's live mirror.
  • Integration markers provided for commercial WebGL/WASM engines (e.g. DeepAR, Banuba, or FittingBox).
